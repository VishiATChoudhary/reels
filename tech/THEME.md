# Tech theme

Machine settings: `themes/tech.json`. Recipe: `../RECIPE.md`. Visual teardown of the references: `STYLE.md`.

| | Tech |
|---|---|
| Voices | founders, scientists, engineers: lectures, interviews, documentaries |
| Story shape | "nobody believed it" or "we were unimpressive", then the idea that changed it |
| The drop | the idea ("**blew** the condor away", "machines will **think**") |
| B-roll | archive tech, labs, films (2001, Metropolis), literal objects for each phrase |
| Grades | before `COLD BLEAK TEAL`, turn `AMBER TEAL`, after `VIVID AMBER RED TEAL COLD`, speaker `WARM` |
| Frame | `card` |
| Music | Encore Kanye-type beats, the whole pool |
| Headline | the name and the curiosity gap: "steve jobs found the answer in a study about *birds*" |

Done: Jobs (x2), Feynman, Selfridge + Shannon, Clarke, Hinton, Move 37, Karpathy, Hassabis, Jensen, Hopper.
P02 is the reference spec (`episodes/p02-jobs-arc.yaml`); P03 to P12 were built with the older per-episode
scripts in `sources/` and still rebuild from there.
