# Sports theme

Machine settings: `themes/sports.json` (song pool, grades, frame, handle). Recipe: `../RECIPE.md`.

| | Sports |
|---|---|
| Voices | athletes, coaches, locker-room speeches, press conferences, commentary calls, sports films |
| Story shape | doubt, loss or pressure, then the comeback |
| The drop | the call or the line that turns it: the shot, the knockout, "YES!", the finish line |
| B-roll | the actual game: slow motion, crowds, empty gyms at 5 am, the scoreboard, the tunnel walk |
| Grades | before the drop `NIGHT BLEAK COLD BW`, turn `AMBER COLD GOLD`, after `GOLD VIVID RED AMBER` |
| Frame | `wide` (the FEROX look, 1080x955, hard edges) by default |
| Music | the harder Encore beats: HUMBLE YOURSELF, MERCY, STORMS COMING, MEDUSA |
| Headline | the stakes, plain: "he missed 26 game winners. then he said *this*" |

Commentary calls make the best drops: the caller's voice jumps exactly where the beat should.
A two-voice reel works well here: the athlete for the setup, the commentator for the climax.
